AI voice receptionist

A production voice agent taking live clinic calls end to end — intent, booking, rescheduling, no human in the loop.

PipecatReal-time SpeechLLMsPython

AI voice receptionist

Problem
A doctor's clinic losing staff hours to inbound calls that were almost entirely booking and rescheduling.
Build
A real-time backend pipeline on Pipecat, orchestrating speech-to-text, LLM reasoning and text-to-speech inside a latency budget tight enough for natural turn-taking.
Hard part
Not the happy path — the edge cases. Interruptions mid-sentence, ambiguous speech, dead silence, and requests outside the agent's scope, each needing a fallback that doesn't strand the caller.
Outcome
Deployed and taking live calls end to end, managing the full booking and rescheduling flow without a human in the loop.

Industrial drawing pipeline

ETL over multi-layer DXF files — extracting, validating and transforming geometry into something a compliance agent can reason about.

PythonezdxfRAGGNNLangChain

Industrial drawing pipeline

Context
A government-scale platform for the Goa Industrial Development Corporation, built under a Deloitte contract inside a compliance-audited delivery model.
Problem
Industrial drawing files arrive as multi-layer DXF with no consistent convention between sources — the same floor plan might be structured five different ways.
Build
ETL pipelines using ezdxf that extract, validate and transform the geometry, isolating floor plans, site plans and elevations regardless of how the source file was organised.
Models
CNN-based entity detection, StyleGAN for synthetic training data where real samples were thin, and Graph Neural Networks modelling the structural relationships between drawing elements.
Feeds
All of it into a RAG-based LLM compliance agent — Llama models orchestrated through LangChain — so the reasoning layer sees structure rather than raw vectors.

Long-term memory layer

Persistent recall for a chatbot that forgot everything between sessions — tenant-scoped, entity relationships held across conversations.

mem0pgvectorMulti-tenancyJWT

Long-term memory layer

Problem
An existing RAG chatbot had retrieval but no memory — every session started from zero, and it couldn't connect facts about the same person across conversations.
Build
Integrated mem0 to give it persistent recall plus entity-relationship awareness, so it holds who relates to what rather than just matching text.
Architecture
Designed to serve several client platforms from one service: JWT-scoped authentication, per-tenant vector database routing through a connection map, and pgvector-backed memory storage with metadata filtering.
Isolation
A shareable flag on each memory governs whether context can cross a tenant boundary — the piece that made one shared service acceptable instead of one deployment per client.

Jammin.ai — audio analysis backend

Stem separation, transcription and forced alignment chained into one orchestrated pipeline, each stage handing cleaner signal to the next.

DemucsCTCStep FunctionsLambda
jammin.ai

Audio analysis backend

Problem
An existing music-learning backend that was both too slow and not accurate enough — audio took too long to ingest, and the analysis on the other end was noisy.
Build
Sped up YouTube audio ingestion, improved transcription, and added 4-stem source separation with Demucs.
Best result
Chord detection already existed, but separation raised its accuracy substantially — handing it isolated instrument tracks instead of a mixed signal fixed the quality problem without touching the detection code.
Timestamps
CTC forced alignment between the audio and its transcription, which is what makes the output land on the right beat rather than approximately near it.
Infrastructure
Deployed on AWS with Step Functions orchestrating the stages across Lambda and EC2, backed by RDS and DynamoDB.

Multi-node automation

Ansible playbooks driving mixed-OS nodes from one control box, with Jenkins triggering playbook runs on every commit and Splunk watching all of it.

AnsibleJenkinsSplunkCI/CD

Multi-node automation

Problem
Configuring machines one at a time, by hand, with no shared record of what state any of them were actually in.
Build
Ansible playbooks driving multiple nodes running different operating systems from a single control node, so setup becomes a file rather than a sequence of remembered steps.
Visibility
Centralised monitoring for every managed node in Splunk, using reverse IP-based identification to route and organise logs by source machine.
Automation
A Jenkins pipeline watching a GitHub repository, building, testing and deploying on each commit — wired into Ansible so a pipeline run can trigger playbook execution directly, connecting CI to the infrastructure layer.

Exotel telephony for Bolna

Project
Bolna, an open-source framework for orchestrating LLM voice agents, which supported Twilio and Plivo but not Exotel.
Contribution
Added Exotel telephony support alongside the existing providers, following the conventions the codebase already used rather than bolting on a parallel path.

Estimate depth from stereo image pairs, contributing to research on spatial awareness and 3D scene understanding.
